# Jeu de Calcul Mental CE2

Jeu éducatif de calcul mental conçu pour les élèves de CE2, utilisable via GitHub Pages.

## 🎮 Comment jouer

1. Ouvrez le jeu dans votre navigateur en accédant à l'URL du dépôt GitHub Pages
2. Répondez aux questions de calcul mental dans le temps imparti
3. Gagnez des points pour chaque bonne réponse
4. Passez à des niveaux plus difficiles au fur et à mesure

## 📚 Types d'exercices

Le jeu propose 5 niveaux d'arithmétique adaptés aux élèves de CE2 :
- Niveau 1 : Additions simples (1-20)
- Niveau 2 : Soustractions simples (1-30)
- Niveau 3 : Multiplications simples (1-10)
- Niveau 4 : Additions plus complexes (10-50)
- Niveau 5 : Soustractions plus complexes (20-60)

## 🎯 Fonctionnalités

- Chronomètre pour ajouter de la tension
- Système de points et de niveaux
- Barre de progression visuelle
- Feedback immédiat sur les réponses
- Interface amicale et colorée pour les enfants

## 🔧 Pour héberger le jeu

Pour utiliser ce jeu avec GitHub Pages :

1. Créez un dépôt GitHub
2. Copiez tous les fichiers (index.html, style.css, script.js) dans votre dépôt
3. Activez GitHub Pages dans les paramètres du dépôt
4. Le jeu sera accessible à l'URL : `https://<votre-nom-utilisateur>.github.io/<nom-du-dépôt>`

## 📱 Responsive

Le jeu est entièrement responsive et fonctionne sur mobile, tablette et ordinateur.
